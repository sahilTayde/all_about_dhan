## Technical model A — **Little rizzie measured move**

**Teacher name:** little rizzie (renamed on show; Fib-like without drawing Fibs).

| Step | SOURCE_FACT | UNKNOWN / gaps |
|------|-------------|----------------|
| **Form (downtrend)** | Drop → bounce → descending **trendline** across bounce highs | Exact touch count / magnet |
| **Measure** | On the candle with the **lowest low** in the pattern: vertical distance from that **low** up to the **TL** on the same candle | Which candle if multiple lows |
| **Target** | Project that distance **below** the low = next downside extension | |
| **Uptrend inverse** | Rise → pullback → ascending TL; measure high→TL on high candle; project **above** | |
| **Trend intact** | Keeps forming rizies hitting projected points | Subjective |
| **Invalidation** | **Closes** beyond the pattern TL | Wick tests OK |
| **Entry (intraday)** | After initial drop, wait bounce; if TL forming, may short for the measured target | Discretionary early TL |
| **Not a rizzie** | Single spike through without bounce/TL structure | Guest whiteboard example |

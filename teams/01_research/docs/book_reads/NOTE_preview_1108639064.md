## Microstructure / fills — topic depth (from the **prior** preview, paraphrase)

The object of study is the **limit order book**: posted size, cancels, marketable hits. A chart mid or bar close is a **summary**, not a guaranteed fill. Liquidity providers charge a **spread**; a marketable order **impacts** the quote. Impact is a **cost** with brokerage. Parent orders split into children; literature in the unread TOC: square-root impact, **impact decay**, **slippage**. Displayed size is **thin**; much interest is **latent**; providers pull when flow looks informed. Prices are **order-driven**, not an exogenous random number the option must follow.

# exitlab

Paper/replay exit harness for NIFTY option-buyer exits. No Dhan calls. New V2
playbook is **opt-in and OFF by default**.

```bash
python -m exitlab --help
python -m exitlab research --data .local_data --out /tmp/exitlab-run --seed 7
```

See `docs/research/exit_lab/REPORT.md` for tables and reproduce commands.

# Exam note — POC / volume profile is HYPOTHESIS, not law

**Layer:** `HYPOTHESIS`  
**Chair:** phd_math · **NO_PROMOTE**

## What the oral wants

**Point of control (POC)** is the price bin with the **most volume** (or TPO count) in a chosen window. **Value area** is a conventional band around that distribution. These are **descriptive statistics of a histogram**, not a physical magnet and not a dealer mandate.

DhanHQ / MCP day-1: OPTIDX **OHLC + OI**, not a vendor VPVR series. Any “silver line” POC we code is **ours** from those bars — label `HYPOTHESIS`.
